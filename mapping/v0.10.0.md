# MOTP v0.10.0 모딩 ID 매핑

이 문서는 v0.10.0의 모딩용 이름표를 고정해 둔 표다. 다음 버전에서 이름표가 바뀌면 이 파일을
고치지 않고 새 버전 파일을 추가한다.

**v0.8.0 표에서 달라진 것** — 셋이다.

- **그림 `photo.grad-group-1-35`가 없어졌다.** 『과거의 추억』을 든 사람의 타이틀이 바꿔 끼우던
  「서른다섯 명 판」 사진인데, 벚꽃길 단체사진 두 장이 처음부터 서른다섯 명이 찍힌 원본이라 바꿔 끼울
  대상이 없었다(파일도 한 번도 실린 적이 없다). 그 타이틀은 이제 같은 사진의 바램이 걷히는 것으로
  달라진다. 이 ID를 덮던 모드는 「모르는 ID」 경고를 받는다 — 타이틀 사진을 바꾸고 싶으면
  `photo.grad-group-1`을 덮는다.
- **효과음 `sfx/tape-play.ogg`가 없어지고 `sfx/broadcast/`가 생겼다.** 방송실 오픈릴의 테이프가 언어마다
  한 벌씩 실제 낭독으로 들어왔다.
- **`sfx/rollcall/`의 서른네 파일이 실제로 실렸고, `data/sfx.json`에 `fadeOuts`가 생겼다**(아래).

예:

```json
{
  "assets": {
    "photo.grad-group-1": "res/user/my_group.png",
    "photo.profile.30217": "res/user/profile/my_30217.png"
  }
}
```

논리 ID가 없는 그림도 바꿀 수 있다. 모드의 `res/` 아래에 설치본 `res/`와 **같은 상대 경로**로
파일을 두면 그 경로를 대신 읽는다. 이 경로 방식은 그림과 오디오에 모두 적용된다.

## 효과음 ID (`data/sfx.json`)

효과음 ID는 곧 `res/audio/` 상대 경로다.

`sfx/achievement.ogg`, `sfx/press-run.ogg`, `sfx/patrol-caught.ogg`,
`sfx/rollcall-page.ogg`, `sfx/rollcall-named.ogg`, `sfx/void-catch.ogg`,
`sfx/void-appear.ogg`, `sfx/lockers-rattle.ogg`, `sfx/elevator-door.ogg`,
`sfx/elevator-arrive.ogg`, `sfx/shadow-touch.ogg`, `sfx/film-burn.ogg`,
`sfx/dorm-knock.ogg`, `sfx/dorm-key-slide.ogg`, `sfx/dorm-doors-open.ogg`,
`sfx/time-shift.ogg`, `sfx/key-open.ogg`, `sfx/key-reject.ogg`,
`sfx/wire-cut.ogg`, `sfx/wire-connect.ogg`, `sfx/wire-reject.ogg`,
`sfx/typewriter.ogg`, `sfx/ui-hover.ogg`, `sfx/ui-click.ogg`, `sfx/write.ogg`,
`sfx/broadcast/tomorrow-ko.ogg`, `sfx/broadcast/tomorrow-en.ogg`, `sfx/broadcast/tomorrow-ja.ogg`.

접두 경로로 묶인 파일군이 둘 있다.

| 접두 경로 | 파일 | 쓰임 |
|---|---|---|
| `sfx/rollcall/` | `30201.ogg` … `30234.ogg` | Ch6 지하 「공란」의 호명. 학번 사진(`user/profile/302NN.png`)과 같은 이름표이고, 화면 언어와 상관없이 같은 파일이 울린다 |
| `sfx/broadcast/` | `broadcast-tape-ko.ogg` · `-en.ogg` · `-ja.ogg` | Ch2 방송실 「되감기지 않은 릴」의 테이프. 화면 언어(모드 언어면 그 언어가 기대는 정본 언어)의 것이 울린다 |

**테이프를 바꾸는 모드는 길이와 말의 자리를 원본에 맞춰야 한다.** 화면의 대본 줄은 원본 녹음에서 사람이
입을 떼는 시각에 하나씩 뜬다 — 그 시각표는 데이터 파일이 아니라 게임 안에 있으므로, 말의 자리가 다른
녹음을 넣으면 줄과 소리가 어긋난다.

파일 교체는 같은 경로의 `res/audio/...`를, 음량 변경은 `data/sfx.json`의 `volumes` 또는 `prefixes`를 쓴다.
`fadeOuts`(v0.10.0)는 **소리 끝의 페이드 길이**(㎳)를 접두 경로 단위로 정한다 — 기본값은
`{ "sfx/rollcall/": 220 }` 하나다. 파일을 다시 인코딩하지 않고 재생할 때 거는 것이라, 끝이 뚝 끊기는 소리를
가진 모드는 이 표에 한 줄을 더하면 된다.

## v0.6.0 → v0.8.0에서 바뀐 것

**위의 이름표(그림·BGM·효과음·글꼴·데이터 파일)는 하나도 안 바뀌었다.** 바뀐 것은 판정이 도는 자리와
조건의 어휘다 — 게임의 규칙이 Rust 엔진으로 옮겨 가면서(v0.8.0), 게임 자신의 목표·도전과제가 모드의
JSON과 **같은 선언형 조건**으로 적히게 됐다.

### 조건 어휘 (`data/objectives.json` · `data/achievements.json`)

새로 쓸 수 있는 조건:

| 조건 | 뜻 | 어디서 |
|---|---|---|
| `{ "all": [ … ] }` · `{ "any": [ … ] }` | 조건 목록의 그리고/또는 | 둘 다 |
| `{ "observedAll": [ "flagA", "flagB" ] }` | 목록이 **비어 있지 않고** 전부 섰다 | 둘 다 |
| `{ "allDocuments": [ … ] }` | 문서를 전부 모았다(빈 목록은 거짓) | 둘 다 |
| `{ "allItems": [ … ] }` | 소지품을 전부 들고 있다 | 둘 다 |
| `{ "countOf": [ … ], "atLeast": 2 }` | 목록 중 선 표식이 n개 이상 | 둘 다 |
| `{ "difficulty": "hard" }` | 이 회차의 난이도 | 둘 다 |
| `{ "hiddenSeen": true }` | 「과거의 이상」을 본 적이 있다 | 도전과제만 |
| `{ "endingOn": { "difficulty": "superHard", "ending": "true" } }` | 그 난이도로 그 갈래를 봤다(`ending` 생략 = 아무 갈래나) | 도전과제만 |
| `{ "ledgerAllExcept": "myPerfect" }` | 지금 판정 중인 목록을, 그 한 장만 빼고 전부 땄다 | 도전과제만 |

기존 어휘(`flag` · `allFlags` · `anyFlags` · `not` · `chapter` · `scene` · `item` · `document` · `always`,
도전과제 전용 `ending` · `clearsAtLeast` · `achievement`)와 **오류 문장은 그대로**다.

### Advanced

- **mixin 대상 11개는 이름·규약이 그대로다.** 판정 함수 안쪽이 Rust로 바뀌었을 뿐, `motp.mixin.inject`는
  같은 자리에 걸린다.
- `motp.internal`의 모듈 목록에 `engine/core`가 더해졌다(여전히 **아무 약속도 없는** 층이다). 옛
  목록의 모듈은 그대로 열리지만, 그 안의 판정 함수들은 이제 엔진을 부르는 얇은 파사드다.
- `motp.achievements.define`의 `earned`는 여전히 **함수**를 받는다 — 함수 판정자만 JS에서 돌고,
  선언형 조건은 엔진이 판정한다.

### `data/difficulty.json`이 이제 실제로 먹는다

v0.7.0까지는 난이도 감사기가 忘却·花様의 힌트 예산 0(설계값)을 문제로 셌고, 조율 모드는 얹을 때마다
감사를 통과해야 해서 **모든 `difficulty.json`이 통째로 물리쳐졌다**. v0.8.0에서 고쳤다 — 이제 추격을
필연 피격으로 만드는 값처럼 **정말로 문제가 있는 조율만** 물러난다.
